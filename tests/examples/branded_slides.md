# Branded Presentation Example

This presentation uses a custom `.pptx` template for branded styling.

## Why Use Templates?

Templates let you maintain **visual consistency** across all your presentations:

- Corporate colors and fonts
- Branded title slides
- Consistent layout structure

## How It Works

1. Design your template in PowerPoint
2. Export it as `.pptx`
3. Pass it to `md2pptx` with `--reference-doc`

```bash
md2pptx slides.md --reference-doc Presentation1.pptx
```

## Key Benefits

- **Speed**: Write in Markdown, get branded slides
- **Consistency**: Same look across all decks
- **Version control**: Track content changes in Git

## Conclusion

Markdown + Templates = Professional presentations in seconds.
